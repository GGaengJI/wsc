# PhoneCam

아이폰을 Windows PC의 웹캠처럼 쓰는 웹 페이지입니다. 앱 설치 없이 아이폰 Safari와 OBS Studio만 있으면 됩니다.

주소: https://ggaengji.github.io/wsc/

## 처음 한 번 (PC)
1. [OBS Studio](https://obsproject.com/) 설치 (무료)
2. PC 브라우저로 위 주소 → **PC: 받는 화면 열기**
3. 아이폰 기본 카메라로 화면의 QR을 찍어 페이지를 열고, 즐겨찾기에 추가
4. 받는 화면 아래 **OBS 브라우저 소스에 넣을 주소** 복사 → 브라우저 받는 화면은 닫기
5. OBS → 소스 `+` → **브라우저** → 주소 붙여 넣기, 너비 1920 · 높이 1080
6. OBS **가상 카메라 시작** → Discord 등에서 카메라로 **OBS Virtual Camera** 선택

## 매번
OBS를 켜고 가상 카메라 시작 → 아이폰에서 즐겨찾기를 열고 **카메라 켜고 연결**

## 아이폰 화면의 버튼
| 버튼 | 내용 |
|---|---|
| 전면/후면 전환 | 카메라 바꾸기 |
| 화질 | 1080p 30fps(기본) · 1080p 60fps · 720p 30fps |
| PC로 소리 보내기 | PC 마이크가 없을 때 아이폰 마이크 사용 (128kbps) |
| 배경 | 그대로 · 흐리게 · 스튜디오 · 어둡게 · 내 사진 |
| 조명 / 피부 보정 | 끔 · 약하게 · 강하게 |
| 배경 사진 고르기 | 아이폰 사진을 배경으로 사용 |
| 회전 / 좌우 반전 | 아이폰을 뒤집거나 눕혀 놓았을 때 방향 맞추기 |

효과는 PC에서 처리하므로 아이폰에는 부담이 없습니다. 효과를 모두 끄면 원본 화질 그대로 나갑니다.

## 알아 둘 것
- 아이폰과 PC가 **같은 와이파이**에 있어야 합니다. 영상은 집 안에서만 오갑니다. 두 기기가 처음 서로를 찾을 때만 인터넷의 무료 연결 서버(PeerJS)를 씁니다.
- 아이폰 화면이 꺼지거나 Safari를 벗어나면 영상이 멈춥니다. 충전기에 꽂아 두세요.
- 아이폰 소리를 Discord 마이크로 쓰려면 VB-Cable 같은 가상 오디오 장치가 따로 필요합니다.
- 연결 코드(QR)가 남에게 보였다면 받는 화면에서 **새 코드 만들기**를 누르고 QR을 다시 찍으세요.

## 보안
- 연결 코드는 PC 브라우저가 무작위로 만들고 그 브라우저에만 저장합니다.
- 영상을 보내기 전에 아이폰과 PC가 서로 코드를 아는지 서명(HMAC-SHA256)으로 확인합니다. 코드 자체는 주고받지 않습니다.
- 연결 서버에는 코드를 해시한 이름만 등록됩니다. 연결된 경로가 집 안(사설 주소)이 아니면 끊습니다.
- 영상은 WebRTC 규격에 따라 암호화됩니다.

## 사용한 라이브러리
